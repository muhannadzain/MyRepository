# MIRQA Product Specification (living document)

## Product promise
The learner defines a measurable goal. MIRQA identifies relevant prerequisite knowledge, gathers evidence about the learner's current state, and selects the next useful learning action.

## MVP success criteria
- Runs without internet, account, API key, or server.
- User can choose a defined learning goal.
- Diagnostic questions are linked to stable concept IDs.
- The engine can explain why it selected a question or learning action.
- Progress is stored locally in a later MVP milestone.
- No mastery claim is made without defined evidence rules.
- The learning content is reviewed and traceable to sources.

## MVP exclusions
- Universal support for every subject.
- Unrestricted AI-generated lessons.
- Cloud sync and social features.
- Claims of expert-level mastery assessment.
- Automatic ingestion of arbitrary web content.

## First pilot
An introductory, carefully scoped path toward understanding a few foundational ideas used in general relativity. Content and prerequisite relationships must be reviewed against reliable educational sources before being presented as a validated curriculum.
