# AlertMe — تنبيه الرسائل المهمة

تطبيق أندرويد بيراقب رسائل **واتساب** و**تلجرام**. لو وصلت رسالة من شخص (أو من شخص في جروب معين) حددته، بيطلعلك:

- نغمة رنين من اختيارك (بتفضل شغالة لحد ما تدوس موافق)
- صورة من تصميمك في منتصف الشاشة (حتى على شاشة القفل)
- زر **موافق** لإيقاف التنبيه

## إزاي بيراقب؟

| التطبيق | الطريقة |
|---|---|
| **تلجرام** | اتصال مباشر بحسابك عن طريق **TDLib** (المكتبة الرسمية من تلجرام). مش محتاج إشعارات خالص. |
| **واتساب** | مفيش API رسمي لحساب شخصي، فبيقرأ **إشعارات** واتساب. لو مقفلها خالص مش هيشتغل، خليها شغالة بس **صامتة** (بدون صوت/pop-up). |

## البناء على GitHub Actions

1. ارفع محتوى المجلد على ريبو جديد في GitHub (فرع `main`). **الأفضل Public** (بناء TDLib تقيل على الأجهزة الصغيرة).
2. تبويب **Actions** → `Build APK` بيشتغل تلقائيًا.
3. **أول مرة بس** هيبني TDLib من السورس الرسمي (حوالي ساعة). بعد كده بيتخزن في الـ cache والبناء بياخد دقايق.
   - لتحديث TDLib: غيّر `TDLIB_CACHE_VERSION` في `.github/workflows/build.yml` (مثلًا `v2`).
   - GitHub بيمسح الـ cache لو ما اتستخدمش 7 أيام (هيتبني تاني تلقائيًا).
4. نزّل الـ artifact **AlertMe-apk** → جواه `app-debug.apk` وثبّته.

> مفيش مفاتيح سرية في المشروع. الـ API ID/Hash بتدخلهم في التطبيق نفسه.

## تلجرام: أول تشغيل

1. ادخل **my.telegram.org** بحسابك ← **API development tools** ← اعمل تطبيق واحصل على `api_id` و`api_hash`. (ماتشاركهمش مع حد)
2. في التطبيق: **تسجيل الدخول لتلجرام** ← اكتب API ID وAPI Hash ورقمك (+20...).
3. هيوصلك كود على تطبيق تلجرام عندك (أو SMS) → اكتبه. ولو عليك تحقق بخطوتين هيطلب كلمة السر.
4. بعد ما الحالة تبقى ✅ **متصل** يشتغل في الخلفية بإشعار دائم صغير (ده اللي بيمنع النظام يقتله). وبيرجع لوحده بعد إعادة تشغيل الموبايل.

## تحديد الشخص والمكان

**الشخص** (خانة واحدة، والتطبيق بيفهم النوع لوحده):

| بتكتب | بيطابق |
|---|---|
| `Ahmed` | اسم المرسل (يحتوي على النص) |
| `@ahmed_99` | اليوزرنيم بالظبط (**تلجرام بس**) |
| `+20 100 123 4567` أو `0100...` | الرقم (بآخر 9 أرقام) |

- رقم تلجرام بيشتغل لو الشخص في جهات اتصالك أو رقمه ظاهر لك. لو مخفي استخدم اليوزرنيم.
- رقم واتساب بيشتغل لو الرقم ظاهر في الإشعار (جهة اتصال غير محفوظة)، غير كده استخدم الاسم.

**المكان** (لكل شخص):

- **أي مكان**: الخاص وكل الجروبات.
- **الخاص فقط**: رسايله في الشات الخاص بس، ويتجاهل أي جروب.
- **جروب محدد فقط**: اكتب اسم الجروب **بالظبط**. لو هو معاك في جروبين، الجروب التاني ما بيرنش. لو عايز جروبين، ضيف نفس الشخص مرتين.

## الإعداد العام

1. **السماح بالعرض فوق التطبيقات** (مهم عشان التنبيه يفتح لوحده والموبايل مقفول).
2. **إيقاف توفير البطارية** للتطبيق.
3. لواتساب: **تفعيل قراءة الإشعارات**.
4. اختار **الصورة** و**النغمة**، وجرّب بزر **تجربة التنبيه**.
5. **إضافة شخص**: الاسم زي ما هو ظاهر عندك، واسم الجروب لو عايزه محدد (اختياري)، واختار واتساب و/أو تلجرام.

## لو التنبيه مش بيظهر إلا لما تفتح التطبيق

التنبيه بيظهر كنافذة فوق أي تطبيق (محتاج إذن "العرض فوق التطبيقات")، لكن عشان تلجرام يفضل متصل في الخلفية لازم النظام ما يقتلش التطبيق. في الموبايلات الصينية (شاومي/أوبو/ريلمي/هواوي...) لازم:

1. **البطارية**: إعدادات التطبيق ← البطارية ← "بدون قيود" (No restrictions).
2. **التشغيل التلقائي** (Autostart): فعّله للتطبيق.
3. **قفل التطبيق في الـ Recents** (اسحب لتحت أو اضغط قفل على كارت التطبيق).
4. "العرض كنافذة منبثقة في الخلفية" (Display pop-up windows while running in the background) لو موجودة عندك.
5. من التطبيق: صفوف الصلاحيات كلها ✅، وتحت "تلجرام" هتلاقي **الاتصال** و**آخر نشاط**. لو آخر نشاط قديم بعد ما تقفل التطبيق يبقى النظام قتله أو جمّد الشبكة.

## ملاحظات

- تلجرام: بيتنبه على الرسايل اللي وصلت في آخر 30 دقيقة بس (عشان ما يرنش على رسايل قديمة بعد ما الموبايل يرجع من أوفلاين).
- المطابقة بالاسم بتتجاهل التشكيل والهمزات (أ/إ/آ = ا).
- لو جروب/شخص عاملهم Mute في تلجرام هيتنبه برضه (التطبيق بيقرأ الرسايل مش الإشعارات).
- لو غيّرت API ID: سجّل دخول تاني من نفس الزر وهيعيد التشغيل.
- لو فتحت المشروع في Android Studio محليًا، ملفات TDLib (`org/drinkless` و`jniLibs`) بتتضاف من GitHub Actions بس. محليًا هتحتاج تبنيها بنفسك من `example/android` في ريبو tdlib/td.
- لتغيير اسم الحزمة: `applicationId` و`namespace` في `app/build.gradle.kts`.
